# TheJamesPeters.github.io

Root GitHub Pages site for TheJamesPeters apps. It serves
[`app-ads.txt`](https://thejamespeters.github.io/app-ads.txt), which AdMob and other ad networks
check at the root of the developer website on each app's store listing. Every app whose listing
points to a page on `thejamespeters.github.io` is covered.

Each app keeps its own site in its repo (for example
[Squishcord](https://thejamespeters.github.io/squishcord/)).

To add another ad network or account, add the line that network gives you to `app-ads.txt`.
